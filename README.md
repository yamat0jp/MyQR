インストール・アンインストール:


ダウンロードして展開すれば使える状態です。インストール

不要。アンインストールもファイルを削除で終わります。

使い方:


起動して表示フォームにマウスカーソルを持っていき、

続いて画面上のQRコードの上を覆います。

しばらく待つと標準のブラウザでURLをひらいてくれます。

邪魔な時にはクリックで最小化できます。

サイズは右クリックで変更できます。


使いやすくするにはツールバーに登録しておくとよいでしょう。
